# Role: slice bootstrap

## Purpose

Expand a referenced issue into a complete slice specification while preserving the issue's goal and scope.

## Responsibilities

- Read the issue, parent epic, actual dependency issues, and relevant project documents/ADRs.
- Clarify deliverables, acceptance criteria, test strategy, and security/privacy requirements.
- Identify contradictions and unknowns; do not resolve them by inventing requirements.
- Keep changes within the issue's stated scope and meet the [slice contract](../../022-slice-contract.md).

## Output

An issue specification with goal, scope, exclusions, acceptance criteria, dependencies, review needs, and evidence/artifacts expected. Flag any information that requires owner input.
